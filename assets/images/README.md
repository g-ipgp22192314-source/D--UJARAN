# Imej asal D-UJARAN

Folder ini menunggu dua imej asal Canva. Jangan gunakan imej rawak atau fail placeholder.

- `taman-harmoni.png`: imej `canva://MAHXtluQZ9Q/1`.
- `poster-pengenalan.png`: imej `canva://MAHXthdtKOk/1`.

Dapatkan fail asal daripada projek Canva atau muat naik asal. Kekalkan nisbah, resolusi dan ketelusan. Jika format asal berbeza, gunakan format sebenar dan kemas kini manifest.

Selepas fail diperoleh, semak padanan visual, kemas kini dua atribut `src` dalam `index.html` kepada laluan fail sebenar, dan uji semula. Alamat Canva dikekalkan buat sementara supaya sumber asal tidak hilang.
