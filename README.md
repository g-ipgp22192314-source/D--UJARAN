# D-UJARAN B2 – GitHub Pages

## Cara terbit
1. Cipta repository **Public** di GitHub.
2. Extract ZIP dan upload **semua kandungan folder** (index.html, assets, README.md), bukan ZIP.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Tunggu beberapa minit untuk pautan username.github.io/nama-repository/.

## Tambah gambar
Upload gambar PNG ke `assets/images/` dengan nama ID yang dipaparkan pada setiap kad, contohnya `B2_U01_G01.png`. Gambar yang belum dimuat naik memaparkan teks gantian.

## Tambah audio
Upload MP3 ke `assets/audio/` mengikut nama ID audio yang ditunjukkan pada Panel Guru, contohnya `B2_U01_A01.mp3`. Audio soalan menggunakan nama seperti `B2_U01_Q01.mp3`.

## Muzik latar
Upload MP3 dengan nama tepat `assets/audio/muzik-latar.mp3`. Muzik hanya bermula apabila pengguna menekan butang MAIN MUZIK (dasar pelayar).

## Had penting
Panel Guru asal daripada Canva belum menyediakan backend. Memuat naik media terus dalam website untuk semua murid **belum disokong**; upload ke GitHub melalui repository. Rekod kemajuan disimpan pada pelayar masing-masing, bukan pangkalan data bersama. Aset gambar dan MP3 asal tidak disertakan kerana tidak terdapat dalam fail kod yang diberikan.
