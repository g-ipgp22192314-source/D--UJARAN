# Audio ujaran guru

Tiada MP3 guru dibekalkan atau direka sebagai rakaman siap. Untuk setiap misi 1–8, sediakan dua fail, contohnya A4_M01_P1.mp3 dan A4_M01_P2.mp3. Terbitkan fail pada hos HTTPS dan tetapkan URL penuh dalam missions.js atau panel guru.

Jika fail diletakkan dalam folder audio ini, URL selepas penerbitan Netlify contohnya https://nama-laman.netlify.app/audio/A4_M01_P1.mp3 apabila folder A4 menjadi akar laman. Jangan gunakan URL contoh itu secara literal; gunakan alamat hos sebenar.

Rakaman murid tidak pernah disimpan dalam folder ini atau dihantar ke hos secara automatik.
